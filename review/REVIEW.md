# Newsdesk 前端审阅说明

公开仓库整理说明：本文记录前端审阅阶段。公开版以通用配置模板替代作者的部署脚本，schema.sql 已补齐新数据库所需诊断列；其余前端验证范围不变。

本次只完成本地修改与验证，未部署。请用户核对后再由原部署方发布。

## 如何看效果

1. 当前电脑可打开 http://127.0.0.1:4173/ 查看本地预览。
2. 预览顶部有“本地审阅预览”提示，74 条资讯是演示数据；操作不会访问线上数据库。
3. 检查首屏标题揭开、插画揭幕、滚动后的模块标题与卡片分批进场。
4. “资讯 / 来源”切换、筛选、搜索、收藏、已读和采集按钮都连接本地演示接口。
5. 如重启预览，在项目目录执行 node review/preview.cjs，保持终端开启；结束时按 Ctrl+C。
6. 开场每个标签页会话播放一次，减少反复刷新对阅读的打扰；需要重看时，在新的浏览器标签页直接输入预览地址。
7. 若系统开启“减少动态效果”，页面会采用静态呈现，关闭视差与进场。

## 视觉与动效

采用米白纸感、墨色排版与黄绿色重点卡片。首屏 STAY / CURIOUS. 通过容器裁切、位移、轻微旋转和压缩归位进入，约 1.7 秒完成。模块英文标题先进入，卡片随后分批 stagger。抽象 SVG 插画有揭幕和最大 14px 的滚动视差。

使用浏览器原生 Web Animations API 与 IntersectionObserver。没有引入 GSAP、ScrollTrigger、外部字体、图片、视频或 WebGL。用户允许 GSAP，本项目用原生动画满足所需效果并延续无生产依赖的部署结构。

## 已修复与优化

- 筛选、搜索可取消旧请求，避免快速切换时旧结果覆盖新结果。
- 统计请求也有版本控制，减少异步返回顺序造成的过期统计。
- 新闻加载失败有明确重试入口；收藏、已读、批量已读、来源设置和采集失败都有反馈。
- 收藏筛选中取消收藏、未读筛选中标为已读时，即时移除不再匹配的条目。
- 复用并延迟创建日期与数字格式化器，避免每条新闻重复构造。
- 保持每页 30 条；来源页在短时间重复切换时复用数据。
- 进场完成立即释放动画对象，移除列表前取消对应观察与动画。
- 视差只在插画可见时注册一个 passive 滚动监听，每帧至多一次测量和写入；离屏、后台或减少动态效果时停止。
- 开场不遮挡操作，不等待开场结束再请求新闻。
- 增加跳转到列表、控件标签、标签页键盘切换、状态提示、手机布局及深色模式。
- 修正辅助文字和重点卡片的对比度。
- “最新入库”对应 /api/stats 的 last_fetch，避免把文章入库时间误称为最近采集；来源页保留真实“最近尝试 / 最近成功”。

## 功能与浏览器验证

24 项本地自动检查全部通过，包括原文新标签跳转及异步已读、收藏保存与刷新、筛选移除、分类地区、搜索请求竞争、30→60→74 分页、来源诊断转义、来源启停、采集状态、标签页键盘切换、失败重试、变更失败反馈、批量已读、减少动态效果、滚动监听移除、反复切换后无残留动画、响应式布局、深色模式、x-newsdesk 请求头与无未捕获脚本错误。

Edge 157 无头浏览器，1440px、768px、390px 与 320px 视口。WCAG A/AA 自动扫描在桌面和手机深色场景中未报告违规；自动扫描不能替代完整人工可访问性验收。

另外已针对来源页首次加载的滚动定位和快速切换做定向验证，均通过。

接口均为本地模拟。没有连接生产 D1、执行真实采集、重新验证生产 Access 或真实站外媒体可达性。原文测试由本地路由接管测试地址。

## 性能实测与范围

完整数据见 performance-results.json。每个版本和场景只有一次实验样本，采用本地回环接口、未限速网络；手机场景是 390px 视口加 4 倍 CPU 降速，不是真机。数值不等于生产环境成绩。

- 新页面 HTML 44,441 字节；离线 gzip 14,461 字节。旧页面 12,371 字节、gzip 5,243 字节。新增视觉与交互带来约 9KB gzip 增量。
- 新版没有额外的第三方 JS、字体或媒体请求。
- 本次桌面新版 FCP / LCP 均为 152ms，CLS 为 0。
- 本次手机 4 倍 CPU 降速新版 FCP 为 416ms，LCP 为 1,964ms，CLS 为 0。
- 相同实验中的旧版手机 FCP 为 332ms、LCP 为 720ms，CLS 为 0.75596。新版开场会延后最大标题的完整呈现，不能声称所有指标都变快。
- 新版初始长任务本次记录为桌面 72ms、手机 90ms；旧版手机记录为 213/100ms。仍有一次超过 50ms 的初始化任务。
- 开场结束后活动动画数为 0；插画离屏后滚动监听数为 0，静止阅读没有持续动画循环。
- 没有实测真实设备滚动帧率和线上冷网络表现。正式发布前应在用户的手机及真实 Access 登录环境做最终检查。
